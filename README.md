# XCoordTrans 软件介绍
1. 软件概述
XCoordTrans 是一款面向测绘、地理信息和工程数据处理场景的桌面坐标转换软件。软件用于在大地坐标、空间直角坐标和高斯-克吕格平面坐标之间进行转换，并支持不同椭球基准、投影参数、坐标转换参数以及高程改正。

软件支持 Windows、Linux 和 macOS 等桌面平台，提供直观的图形化操作界面。

2. 主要功能
2.1 多类型坐标转换
软件支持以下坐标类型之间的转换：

大地坐标 LBH：经度、纬度和椭球高
空间直角坐标 XYZ
平面坐标 yxh：东坐标、北坐标和高程
可根据源坐标和目标坐标类型，完成大地坐标、空间直角坐标与平面坐标之间的转换。

2.2 常用参考椭球
内置以下常用椭球模型：

北京 1954
西安 1980
CGCS2000
WGS84
源坐标和目标坐标可以分别选择对应的椭球模型，以适应不同坐标基准之间的转换需求。

2.3 高斯-克吕格投影
软件支持高斯-克吕格投影及其常用参数设置，包括：

中央子午线
比例因子
投影坐标的源坐标和目标坐标配置
平面坐标与大地坐标之间的相互转换
软件也提供面向常见使用场景的投影转换接口，例如 WGS84 到 UTM、WGS84 到 Web Mercator，以及 CGCS2000 到高斯-克吕格投影的转换。

2.4 参数转换
软件提供三参数、四参数和七参数转换能力，可用于不同坐标基准或局部坐标系统之间的转换。

其中，四参数和七参数支持通过公共点进行计算，并在输入条件不足或参数无法可靠计算时给出提示。

2.5 单点与批量转换
软件提供两种工作模式：

单点转换：输入一组坐标，快速查看转换结果。
文件转换：选择一个或多个文本文件或 CSV 文件，按照字段格式读取坐标，批量转换后生成输出文件。
批量转换过程中会显示处理进度，并保留文件记录结构，仅更新相应的坐标字段。对于经纬度字段，软件支持转换为多种角度格式。

2.6 多种经纬度格式
经纬度支持以下输入或输出格式：

度、分、秒格式，例如 111:00:00
十进制度格式
紧凑的度分秒格式
带度、分、秒符号的格式
dms 格式
软件会在内部将角度统一转换为十进制度参与计算，并按照用户选择的格式输出结果。

2.7 高程拟合与大地水准面改正
软件可结合大地水准面模型进行高程处理，将椭球高转换为适用场景下的高程结果，并支持相关模型和处理参数配置。

对于大规模点数据，在满足配置条件时软件可以并行处理高程改正，以提高批量转换效率。

2.8 中英文界面与深色风格
软件支持中文和 English 两种界面语言，语言设置会保存到用户配置中。界面采用深色风格，适合长时间进行数据处理和参数配置。

3. 典型使用流程
3.1 单点转换
选择源坐标类型，例如大地坐标 LBH。
选择目标坐标类型，例如平面坐标 yxh。
选择源椭球和目标椭球。
在投影设置中填写中央子午线、比例因子等参数。
根据需要启用七参数转换、平面转换或高程拟合。
输入源坐标并点击“转换坐标”。
在输出区域查看转换结果。
3.2 文件批量转换
切换到“文件转换”页面。
配置输入和输出字段格式。
选择一个或多个文本文件或 CSV 文件。
确认源坐标、目标坐标和转换参数。
启动文件转换。
在输出文件中查看转换后的坐标记录。
4. 软件适用场景
XCoordTrans 适合以下工作：

测量控制点坐标整理与转换
不同坐标基准之间的数据转换
经纬度与投影平面坐标之间的转换
工程测量数据的批量处理
坐标转换参数计算与验证
高程数据的批量改正
坐标转换结果的检查与整理
5. 软件特点
面向实际测绘数据处理，覆盖单点和批量转换流程
支持常见国内外椭球和坐标基准
支持投影参数和坐标转换参数的可配置处理
支持公共点最小二乘参数计算
支持多种经纬度文本格式
支持中英文界面
支持高程拟合和大地水准面改正
